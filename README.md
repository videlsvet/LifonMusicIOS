# LifonMUSIC 🎧 (iOS Version)

Нативная версия музыкального плеера **LifonMUSIC** для iOS (iPhone / iPad), разработанная специально для ценителей творчества группы **CUPSIZE**.

Полностью перенесена с Android-версии [ddangershark/LifonMUSIC](https://github.com/ddangershark/LifonMUSIC) на чистый **Swift + SwiftUI**.

---

## ✨ Возможности приложения на iOS

- 🎵 **Вся дискография CUPSIZE**: Стриминг треков и альбомов с бэкенда `https://lifonmusic.lol/api`.
- 🎛️ **Эквалайзер**: 5-полосный графический эквалайзер с пресетами (*Плоский, Бас, Вокал, Рок, Поп, Джаз*) и ручной регулировкой уровней в дБ.
- 📜 **Синхронные тексты песен (Lyrics)**: Автоматическая прокрутка слов в реальном времени с поддержкой формата `.lrc`, подсветка текущей строчки караоке и возможность перемотать трек тапом по строчке.
- 📱 **Экран блокировки и Dynamic Island**: Интеграция с `MPNowPlayingInfoCenter` и `MPRemoteCommandCenter` — управление треками со шторки, экрана блокировки, часов Apple Watch и наушников.
- 🌈 **Динамический цвет (Glow)**: Автоматическое извлечение доминантного оттенка из обложки альбома и адаптивный градиентный фон в плеере.
- 📥 **Офлайн-режим (Скачивание треков)**: Возможность сохранять любые треки в память iPhone и слушать без интернета.
- ❤️ **Избранное**: Синхронизация лайков с сервером и быстрый доступ к любимым песням.
- 👤 **Профиль и Статистика**: Время прослушивания, персональный Топ-5 треков, система достижений (ачивки).
- 📅 **Дорожная карта релизов**: Хронологический список дискографии группы с 2020 по 2026 год.
- ℹ️ **Информация о CUPSIZE**: Полная биография, история группы, участники, интересные факты и ссылки на сообщества.

## 🛠️ Стек технологий

- **Язык**: Swift 5.10+
- **Интерфейс**: SwiftUI (iOS 16.0+)
- **Аудио-движок**: `AVFoundation` (`AVPlayer`, `AVAudioSession`, `AVAudioUnitEQ`)
- **Системная интеграция**: `MediaPlayer` (`MPNowPlayingInfoCenter`, `MPRemoteCommandCenter`)
- **Анализ цветов**: `CoreImage` (`CIAreaAverage`)
- **Сетевой стек**: `URLSession` (`async/await`, `Codable`)
- **Офлайн-хранилище**: `FileManager` (локальные MP3 и обложки) + `UserDefaults`

## 🚀 Как запустить и собрать проект

### Вариант 1: Открытие в Xcode (на Mac)
1. Откройте файл `LifonMusic.xcodeproj` в Xcode.
2. Выберите симулятор (например, *iPhone 15 Pro*) или подключите физический iPhone.
3. Нажмите `Cmd + R` для сборки и запуска.

### Вариант 2: Сборка `.ipa` через GitHub Actions (без компьютера Mac!)
В проекте уже настроен рабочий процесс GitHub Actions: `.github/workflows/build_ios.yml`.
1. Запушьте проект в свой репозиторий на GitHub.
2. Перейдите во вкладку **Actions**.
3. Запустите воркфлоу **Build iOS App (.ipa)**.
4. По завершении скачайте готовый файл `LifonMusic.ipa` из раздела **Artifacts**.

### Установка `.ipa` на iPhone:
- Через **AltStore** или **SideStore** (бесплатно, без джейлбрейка).
- Через **Sideloadly** (Windows / macOS).
- Через **Scarlet** или **TrollStore** (для поддерживаемых версий iOS).
- Через **TestFlight** (при наличии Apple Developer аккаунта).
